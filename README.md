安装：https://shhdhdhj.github.io/wanshitong-install/

手机本地加密笔记与书架；本仓库不包含个人笔记、密码或书籍。

每日一页：中国时间每天约06:17从在线古籍、诗词和开放教材选取一篇尚未发布的原文；保留内容哈希与发布历史，同一天幂等，跨日去重。新页只含原文与出处，不生成翻译或解读。原12篇详解保留。手机只缓存最近48篇新增原文，历史去重记录在服务器保存。来源失败或耗尽时保留上次内容，不循环冒充新增。

原文来自维基文库电子转录或OpenStax教材，各篇注明作者、出处、版本、核验时间和解读入库日期。

已有本地资料不迁移、不上传。请定期导出加密备份。
